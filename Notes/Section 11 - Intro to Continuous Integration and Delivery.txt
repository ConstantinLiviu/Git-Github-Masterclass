69. What is Continuous Integration?

CI - devs frequently merge their code into a central repository where automated builds and tests are run 
CI rules:
 - maintain a single source repository;
 - automate the build;
 - make the build faster;
 - test in a clone of the production environment;
********************************************************************
70. What is Continuous Delivery?

CD - ensures that code is always in a ready to deploy state.
CD Pipeline:
 - CI Stage: code is commited, built and unit-tested
 - Staging: build deployed to a replica
 - Manual approval/Deployment
 - Production: code pushed to prod
